How aat runs each supported agent CLI.

crates/aat-agents has one adapter per agent CLI; it plans the command and parses the output, and aat-run spawns the process. We checked the flags on 2026-10-29 against what the version column lists and the docs each adapter's module comment links.

Common rules

  • Every CLI above reads the prompt from stdin (PromptVia::Stdin), which avoids quoting and the Windows command-line limit of about 32K characters. CommandPlan::display shows the prompt as < <prompt>.
  • aat adds the table's tool-approval flag only when [agents.<cli>] allow-all-tools = true.
  • extra-args come after aat's own flags (for Codex, before resume/-), and the consent preview shows them.
  • aat refuses a model the CLI cannot serve, never substituting one: model: <what is wrong> — <what fixes it>. With no model:, aat uses default-model from config, else the CLI's own default (<cli> default). A default-model without / goes to the CLI as its own model name, such as sonnet.
  • The answer is the CLI's final text (Final), else the last assistant text. A non-zero exit with no answer is an error carrying a bounded, one-line excerpt of stderr; an error the CLI reports in its stream wins over that.
  • Partial and Thinking live events keep the last 2000 characters, Message the first 8000. A tool summary is one line of at most 120 characters: the path, command, URL or query the tool acted on. Lines that are not JSON objects produce nothing, and parsing never panics.

Finding the CLI (detect)

aat uses [agents.<cli>] path if set, else searches PATH. On Windows the search tries each PATHEXT extension (default .COM;.EXE;.BAT;.CMD), then .PS1, and skips the extension-less sh script npm writes beside its shims. Detection runs <cli> --version with a 15 s timeout and kills only the process it started. A version it cannot read is None, not an error.

Windows shims

aat spawns .exe, .cmd and .bat files directly. Rust's std::process::Command runs batch files through cmd.exe /d /c with cmd-safe quoting, and refuses an argument it cannot quote safely (tested with &, spaces and quotes through a .cmd shim). A .ps1 with no .cmd beside it runs as powershell.exe -NoLogo -NoProfile -NonInteractive -ExecutionPolicy Bypass -File <script> ….

aat runs the shim, not the node script behind it: shim layouts differ between npm, pnpm, volta and pi's own shim (which picks a newer node), and the shim is what you run. Killing a .cmd shim kills cmd.exe but not the node process under it, so aat-run stops the whole process tree.

The fake agent

aat-fake-agent (crates/aat-agents/src/bin/aat-fake-agent.rs, logic in aat_agents::fake) stands in for any CLI in tests. Point an adapter at it with path, and pass its options through extra-args, which every adapter appends:

[agents.claude]
path = "target/debug/aat-fake-agent"        # .exe on Windows
extra-args = ["--aat-fake-fixture=crates/aat-agents/tests/fixtures/claude/pong.jsonl"]

It ignores every other argument, reads stdin to the end, replays the fixture to stdout line by line and exits. Each option falls back to an environment variable when absent:

OptionVariableDoes
--aat-fake-fixture=<path>AAT_FAKE_FIXTUREfixture to replay
--aat-fake-exit=<code>AAT_FAKE_EXITexit code
--aat-fake-stderr=<text>AAT_FAKE_STDERRwritten to stderr before exiting
--aat-fake-delay-ms=<n>AAT_FAKE_DELAY_MSsleep before each stdout line
--aat-fake-hangAAT_FAKE_HANG=1sleep an hour after replaying, for timeouts
--aat-fake-record=<path>AAT_FAKE_RECORDwrite the arguments, a --- stdin --- line, then stdin

--version prints aat-fake-agent <version>.

In aat-agents tests, env!("CARGO_BIN_EXE_aat-fake-agent") gives its path. Cargo does not set that variable for a dependency's binary, so another crate either adds a one-line binary of its own, fn main() { std::process::exit(aat_agents::fake::main()) }, or looks for aat-fake-agent next to its test executable after cargo build -p aat-agents.

Checking against a real CLI

real_cli_smoke in crates/aat-agents/tests/process.rs costs a model call, so it is ignored by default. For each CLI in AAT_AGENTS_REAL, it detects the CLI, runs a pong turn from Rust and parses the output:

AAT_AGENTS_REAL=pi,copilot,opencode cargo test -p aat-agents --test process -- --ignored real_ --nocapture

It passed on 2026-10-29 on Windows for pi (via pi.cmd), copilot (.exe) and opencode (via opencode.cmd).
